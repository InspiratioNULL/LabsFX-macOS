### LabsFX is a native macOS app for creating images and music via *ImageFX, MusicFX, and Whisk* 
#### - This service is provided by *Google*, part of the *Google Labs*, or *Google LabsFX* projects

#### *- This app supports Flow Image & MusicFX. The original ImageFX and Whisk are no longer supported*
This app was created with the main goal of acquiring previous creations and downloading them. If you attempted to use an image downloader extensions, it would get the low quality thumbnail versions, and scrolling and downloading them individually meant clicking each one, one-by-one, scrolling would load 12 at a time, until the end of the list. This can take an absurd amount of time. So this app was created to give you an automated way to automatically download the full versions so you don't have to manually, and also auto save creations. 

**And on that note, this app still supports downloading old library items that are no longer accessible on the website!**
# Important 
For those of you who did not migrate their ImageFX history before May 2026.. It is unclear if the items will ever be migrated *anyways* or if endpoint the downloads are sourced from will be taken *offline permanently*. 
- If the above is true, I recommend you download it using the app as soon as possible in case it does indeed get taken offline.
# Features
- Supports creating, and fetching your entire library at once.
- Creations keep record of the prompt used, and there is a reuse prompt feature to recreate images with different models or easy adjustment
- Generated items and even previous creations not created with the app download the original time and date of the creation
- You can set as many prompts as you want, and loop times, so you can have like 3 different prompts, and like 4 loops, which generate 4 images each(or 4 audio tracks) so it will generate each of those 3 prompts 4 times, each producing 4 images, and it will run until you have 48 images generated (unless my math is off, lol. and also unless your prompt accidentally generates inappropriate content on some of the images, it will deliver less than 48)
- Includes native macSO alerts for logged out status, and for inappropriate content errors.
- includes an image viewer and music player, with a favorite system to mark the ones you love
- If you have Gemini API key you can use it to generate variations of a prompt, based on various creative prompts
- Still supports downloading old creations that are no longer accessible from links
- The services provided by Google, available on this app, are completely free, and while you can set multiple prompts and set a loop to continuously generate images with no hard limit on the amount of prompts you are looping, the app does impose safety delays after heavy use.
- Use LabsFX, exclusively on macOS, to download your entire library instantly.
